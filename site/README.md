# workdeck-site

Site de apresentação do [workdeck](https://github.com/thiagofeliperibeiro/workdeck).

Next.js, shadcn/ui, Motion, Magic UI e a paleta Catppuccin Mocha
(`@catppuccin/tailwindcss`), a mesma do tema padrão do workdeck.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

O conteúdo fica em `src/lib/site.ts`.

## Deploy na Vercel

Importe o repositório na Vercel. O framework é detectado sozinho e não há
variável de ambiente para configurar.
